# Legacy Scoreboard Console Trainer

An unofficial, offline-ready training simulator for source-backed All Sport
4000 hockey and ice-rink workflows. It runs in the browser, stores training
progress locally, and never connects to a physical scoreboard.

## Included configurations

- Hockey code 62 without shots on goal
- Hockey code 63 with game-total SOG auxiliary code 196
- Hockey code 63 with period SOG auxiliary code 197
- A clearly labeled 15-minute youth-hockey trainer preset
- Four-digit rink/session timer code 96 for practice, resurfacing, and public
  skate timing

The LL-2274 hockey overlay supports goals, player penalties, penalty-clock
coupling, timeouts, periods, the main clock, and horn controls. Ten guided or
assessed drills cover common operator sequences.
