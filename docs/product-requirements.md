# Product requirements

## Goal

Help rink operators rehearse legacy 4000-series hockey scoring, penalties,
shots-on-goal, clock, period, and horn workflows without live equipment.

## Supported configurations

- Code 62 hockey without SOG
- Code 63 hockey with auxiliary SOG code 196 (game total)
- Code 63 hockey with auxiliary SOG code 197 (period total)
- Code 63 15-minute youth preset, labeled as trainer policy
- Code 96 four-digit timer for general ice-session timing

## Required behavior

- Deterministic main and player-penalty clocks
- Six player-penalty slots per team
- Game and period SOG variants
- Guided, assessment, and free-practice modes
- Offline-ready responsive operation and local-only progress
- Offline-capable arena-horn audio with an operator mute control
- Visible evidence boundary and unofficial-product disclaimer

Physical scoreboard output, proprietary firmware emulation, league-rule
enforcement, remote hardware, and account/cloud sync remain out of scope.
