# ADR 0005: Functional visual recreation

Status: accepted.

Recreate the functional grouping and semantic labels with original CSS. Do not
ship photographs, scans, copied overlay artwork, logos, or fake endorsement.
Behavioral fidelity takes priority over photorealism.

The controller chassis uses the user-supplied photo as a layout reference for
the brushed-metal lid, hinge, left-side sport insert, right-side keypad, arrow
cluster, and yellow/green/red horn/start/stop cues. Branding and artwork remain
original.
